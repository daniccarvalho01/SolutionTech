# Solution Tech

Landing page institucional da **Solution Tech**, criada para apresentar serviços de tecnologia, automação, sites, e-commerces, sistemas sob medida, dashboards e integrações para empresas que desejam reduzir retrabalho e ganhar mais controle operacional.

## Sobre o projeto

Esta landing page foi desenvolvida como página comercial da Solution Tech, com foco em conversão de visitantes em contatos via WhatsApp ou e-mail.

A comunicação principal da página é voltada para empresas que ainda controlam processos importantes em planilhas, fazem digitação repetida ou precisam organizar melhor vendas, atendimento, estoque, financeiro e indicadores.

## Serviços apresentados

- Automação de processos
- Sistemas sob medida
- Sites institucionais
- Landing pages
- E-commerces
- Dashboards e dados
- Integrações com ERPs, CRMs, APIs e planilhas
- Cloud, infraestrutura e suporte técnico

## Oferta principal

A landing page destaca uma oferta de entrada simples:

**Diagnóstico gratuito de 20 minutos**

O objetivo é entender o processo atual do cliente, identificar pontos de retrabalho e sugerir próximos passos para automação, sistema, dashboard ou melhoria digital.

## Como visualizar localmente

Abra o arquivo `index.html` diretamente no navegador.

Como o projeto é uma página estática, não é necessário instalar dependências ou rodar servidor local.

## Como publicar

O projeto pode ser publicado em qualquer hospedagem estática, como:

- Netlify
- GitHub Pages
- Vercel

No Netlify, configure:

- **Branch:** `main`
- **Build command:** deixe vazio
- **Publish directory:** `.`
